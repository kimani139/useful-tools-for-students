### How to contribute (short)
1. Clone the repo: `git clone https://github.com/kimani139/useful-tools-for-students.git`
2. Create a branch: `git checkout -b add-<your-section>-section`
3. Edit `README.md` and replace the comment for your section with your content (at least one paragraph).
4. Commit and push: `git add README.md && git commit -m "Add <Section Name> section" && git push origin add-<your-section>-section`
5. Open a pull request on GitHub and request reviews from team members.
